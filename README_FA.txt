سامانه صدای دانش‌آموز — نسخه دارای ذخیره‌سازی مشترک

شروع سریع در ویندوز:
1) اگر Node.js روی کامپیوتر میزبان نصب نیست، نسخه LTS را از https://nodejs.org نصب کنید.
2) روی کامپیوتری که قرار است پیام‌ها را نگه‌داری کند، فایل start.bat را اجرا کنید.
3) در همان کامپیوتر، آدرس http://localhost:3000 را باز کنید.
4) پنجره سرور را باز نگه دارید؛ پیام‌ها در data\letters.json ذخیره می‌شوند.
5) برای استفاده از کامپیوتر یا موبایل دیگری که به همان وای‌فای/شبکه وصل است، آدرس IP که در پنجره سرور چاپ می‌شود را با پورت 3000 باز کنید؛ برای نمونه http://192.168.1.20:3000 . آدرس دقیق را از خود پنجره سرور بردارید.
6) اگر Windows Firewall پرسید، اجازه دسترسی به شبکه خصوصی را بدهید.

رمز فعلی پنل مدیریت: salamfarmande123

نکته مهم:
- سرور باید روی یک کامپیوتر روشن بماند؛ فایل پیام‌ها روی همان کامپیوتر قرار می‌گیرد.
- localhost روی هر دستگاه به خود همان دستگاه اشاره می‌کند؛ برای دستگاه‌های دیگر از IP میزبان استفاده کنید.
- این بسته برای شبکه محلی (یک وای‌فای/شبکه مشترک) آماده است. برای دسترسی از اینترنت و شبکه‌های مختلف، باید همین سرور روی یک میزبان اینترنتی نصب و اجرا شود؛ صرفاً تغییر JavaScript این محدودیت را رفع نمی‌کند.
- پیام‌هایی که نسخه قدیمی در IndexedDB مرورگرهای جداگانه ذخیره کرده، به صورت خودکار به فایل جدید منتقل نمی‌شوند.
- پیام‌ها و پیوست‌ها به صورت JSON و Base64 در data\letters.json ذخیره می‌شوند. برای پشتیبان‌گیری از پیام‌ها، از این فایل یک کپی تهیه کنید.
- نیازی به npm install یا نصب پکیج اضافه نیست؛ فقط Node.js لازم است.
